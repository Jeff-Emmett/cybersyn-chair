1. Design Philosophy & Aesthetic

PrincipleDescription
Dual SovereigntyEach occupant has full, independent control of their joystick side
Democratic SwitchingEither person can propose a control swap; both must confirm (or one can override)
Cybernetic FeedbackEvery action produces multimodal feedback: visual (LEDs), auditory (tones), haptic (vibration)
No Dead ControlsEvery button does something — even if it's a hidden easter egg
Accessible by DefaultLarge buttons, intuitive joystick, no keyboard needed (honoring the original Cybersyn ethos)
Modular & HackableAll modules hot-swappable, all protocols open, all firmware flashable

Aesthetic Language

  • Shell: White or off-white fiberglass, smooth compound curves
  • Upholstery: Burnt orange (Pantone 1665 C)
  • Controls: Backlit amber buttons, dark bezels
  • Displays: Green-on-black OLED (retro terminal)
  • Joysticks: Matte black aluminum, orange silicone grip
  • Accent Lighting: Addressable RGB, default warm amber

Shell Construction

Single fiberglass monocoque with five integrated zones: backrest, left armrest, left seat, right seat, right armrest. The center console is a raised section between the two seat zones.

Armrest cavities (each): Joystick mount (100×100×80mm), button panel recess (150×120×15mm), electronics bay (200×150×60mm, accessed from underside), cable channel to center console & base.

Swap Mechanism

SWAP button (center dashboard):
• Single press: Initiates swap request — LED blinks on both armrests
• Second person confirms within 3 seconds: Swap executes
• Timeout (no confirm): Swap cancelled, brief buzz feedback
• Double-press by same person: Force-swap (for solo use)
• Hold 3 seconds: Cycle to next mode (Independent → Swapped → Merged → Pilot → Custom)

10. Build Phases

Estimated total: 16–23 weeks

0
Breadboard Proof-of-Concept (2–3 weeks)
Wire all sensors/actuators on breadboard. Validate I2C bus (no address conflicts). Test swap state machine with two joysticks. Measure end-to-end latency (target: <20ms). Run full firmware stack with MQTT publish/subscribe.
1
Custom PCB Design (2–3 weeks)
KiCad schematic & layout: Pi header, I2C/SPI buses, JST-XH connectors for each ribbon cable, screw terminals for power, test points. Fabricate at JLCPCB (2-layer), assemble and validate.
2
3D Printed Armrest Mockup (2–3 weeks)
1:1 scale armrest with joystick cavity, button holes, electronics bay. Install real hardware, test ergonomics with two people. Model and print center console dashboard. Iterate at least once.
3
Fiberglass Shell (4–6 weeks)
Build foam/MDF plug from CAD. Fair and finish to 400 grit. Lay up female mold, then production shell. Bond in cable channels and electronics bay walls. Sand, prime, paint white.
4
Pedestal Base (2–3 weeks)
Cut and weld steel tube + base plate. Mount swivel bearing. Install Pi + PCB enclosure. Load test at 200 kg. Powder coat matte black.
5
Upholstery & Assembly (2–3 weeks)
Cut foam, glue to shell, sew/install fabric. Mount all electronics, speakers, LEDs into shell. Route ribbon cables, connect everything. Mount shell to pedestal. Power-on test.
6
Software Integration & Tuning (2–3 weeks)
Flash DietPi + cybersyn service. Calibrate joysticks. Configure lighting scenes and music library. Implement all 10 easter eggs. Set up Home Assistant. 8-hour soak test.
7
Multi-Couch Network (future)
Couch-to-couch MQTT coordination. Voting/polling across units. Central display wall. Full 7-couch Opsroom mode.
