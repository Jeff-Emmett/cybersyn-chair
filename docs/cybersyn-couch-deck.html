Cybersyn Couch

Dual-Joystick • Mobile • Open Hardware

Two-seater cybernetic couch on wheels. Inspired by Chile's 1971 Operations Room. Every button does something.

Dual Joystick Control

Each armrest: hall-effect 2-axis joystick + 4 Cherry MX buttons. 50Hz polling, 16-bit ADC, haptic feedback per arm.

JoystickHall-effect, +/-25 deg, spring-return
Shaft120mm anodized aluminum, orange grip
Buttons4x Cherry MX per arm (light, scene, music, FN)
Polling50 Hz, 16-bit ADC, 8% deadzone
FeedbackHaptic motor + LED ring per armrest

Center Console

OLED display, SWAP button with cooperative handshake, NFC profile reader, rotary encoders, and 4 easter egg keys.

Row 1LIGHTS • VOLUME • MUSIC • POWER
Row 2SWAP • NFC reader • MODE SELECT
Row 3RANDOM • PARTY • AMBIENT • SECRET
